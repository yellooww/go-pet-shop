# Go Pet Shop

Учебный проект интернет-магазина товаров для питомцев, написанный на Go с использованием PostgreSQL.

## Запуск приложения

Создайте файл .env на основе .env.example:

```bash
cp .env.example .env
```

Запустите приложение вместе с базой данных:

```bash
docker compose up
```

При запуске Docker соберёт приложение, запустит PostgreSQL и выполнит миграции базы данных.

После успешного запуска API будет доступно по адресу: http://localhost:8080

### Запуск тестов

Из корневой папки проекта:

```bash
go test ./...
```

## Версии проекта

### v1 — товары и пользователи

Реализованы CRUD-операции для пользователей и товаров: создание, получение, обновление и удаление записей. Добавлена работа с каталогом товаров и регистрацией пользователей.

### v2 — заказы и позиции заказа

Добавлены создание заказов, добавление товаров в заказ и получение информации о заказах пользователей. Реализована связь между таблицами users, orders, order_items и SQL-запросы с JOIN для получения данных.

### v3 — оформление заказа с транзакцией

Добавлен POST /checkout. Создание заказа, добавление позиций, списание остатков товаров и создание записи в transactions выполняются в одной транзакции PostgreSQL. При ошибке все изменения откатываются, что исключает частичное оформление заказа.

### v4 — история транзакций и заказов

Добавлено получение полной истории заказов и транзакций пользователя по email, а также списка популярных товаров. Для объединения данных используются JOIN, для подсчёта количества проданных товаров — GROUP BY и SUM.
